# RecoveryFlex

This repository contains an auditable repeatable-flexibility screening framework for distribution batteries. An isolated OpenDSS snapshot produces time-indexed charge and export limits; a chronological recovery model then audits repeated service contracts, including a predeclared three-call chronology stress, a fair earliest-charge implementation, and selected nonlinear replay through the feeder.

The current manuscript v5 uses the strict-v4 numerical evidence plus 219 retained 2012–2013 dates, 2,188 baseline-AC-feasible date–group units at each of two primary IEEE 13-node placements, and a fully audited seven-site within-feeder placement extension. It includes an independent zero-power gate, clustered uncertainty intervals, failure records, a binding-constraint audit, a complete 70,016-row three-call gap-by-capacity grid, cumulative-window witnesses, selected nonlinear replay, battery-capacity sensitivities, and a descriptive empirical screening threshold. Strict v4 enforces the declared recovery windows for every policy and reruns selected schedules through nonlinear OpenDSS; the independently audited scalar bounds are reused for parameter sensitivities. The binding audit shows that the 2-MWh endpoint equals the minimum service-window export bound for every baseline-gated unit at all seven sites, while the three-call grid identifies a localized intermediate recovery-window contraction at 634.1 and 500 kWh. The manuscript is intentionally bounded to an offline single-feeder delivery calculation with frozen scalar AC bounds outside the selected replay cell; it is not a real-time controller, probabilistic guarantee, or economic procurement model.

A supplementary OPSD cross-source audit is stored in `results/opsd_cross_source_strict_v5/`: it uses 132 held-out dates from one household profile with train-only normalization on the same IEEE-13 feeder. A separate `results/common_offer_replay_strict_v5/` audit replays site-specific common thresholds through the nonlinear feeder. The v6 `results/common_offer_temporal_evaluation_strict_v6/` audit calibrates one 79.453-kW offer on 7,203 retained 2012 units across seven sites and evaluates it on 8,113 retained 2013 units without site-specific retuning; pooled joint success is 99.150% with a descriptive date-cluster interval. These checks support bounded temporal screening only; they do not establish cross-feeder transferability or a future delivery guarantee.
